Verdict

Fix the glossary at generation time, translate source metadata into one plain availability label, remove internal launch-state copy, and then audit the built and deployed site. Safe launch fixes are included; activating the custom domain is not.

Glossary

Keeps the complete evidence index for lint and diagnosticsAdds a separate canonical row view

Aliases become secondary, searchable entries beneath the canonical term while retaining their own source counts and pointers. New visible-row counts drive the page filters. Literal regression checks cover Crazy, Little Person, duplicates, aliases, and the # bucket.

Sources

Reuses host posture, live status, and archive metadataGroups routes and works by organization
  • Available online
  • Access restricted, with or without a held reference copy
  • Public archive available only when a public file exists
  • Reviewed from a private reference copy
  • Original unavailable

Both the index and detail route become organization-level, so every listed work leads to a page that accurately describes it.

Homepage and name cleanup

Reuses the existing homepage and footerAdds no new component

Remove the homepage Status section and all other public stub, planned, or phase labels. Change the synthesis instruction to impersonal wording. Remove Jordan Krueger’s name from rendered prose and contributor metadata everywhere except the footer.

Launch audit

Reuses lint, verification, Astro, Pagefind, and Direct Upload PagesAdds only verified fixes

Must-pass checks cover content, build, links, accessibility, baseline security headers, preview noindex behavior, and deployment. Local checks run before deploy; live checks run only afterward. CSP enforcement, dependency upgrades, and zone settings before domain attachment are report-only unless a concrete defect is proven.

Decisions

Approved

Keep all cited works, group duplicate organization rows, use accurate availability labels, remove all public build-state copy, preserve glossary alias evidence beneath canonical rows, keep the preview host out of search, remove personal-name references outside the footer, and leave the DNS launch switch untouched.

Open questions

None. Any destructive, billing-related, or public-launch action pauses for approval; the default is to leave it unchanged and report it.
