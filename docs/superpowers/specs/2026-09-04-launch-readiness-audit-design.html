Verdict

Fix the glossary at generation time, translate source metadata into one plain availability label, remove internal launch-state copy, and then audit the built and deployed site. Safe launch fixes are included; activating the custom domain is not.

Glossary

Reuses term aliases and current filtersAdds one canonical row per page

Aliases become secondary text beneath the canonical term instead of duplicate rows. The displayed primary term determines the letter section. A regression check rejects duplicates and wrong-letter placement.

Sources

Reuses host posture, live status, and archive metadataAdds one reader-facing label
  • Available online
  • Archived copy available
  • Access restricted

All cited sources remain listed. A short note explains why unavailable originals stay in the record.

Homepage and name cleanup

Reuses the existing homepage and footerAdds no new component

Remove the homepage Status section. Change the synthesis instruction to impersonal wording. Remove Jordan Krueger’s name from rendered prose and contributor metadata everywhere except the footer.

Launch audit

Reuses lint, verification, Astro, Pagefind, and Cloudflare PagesAdds only verified fixes

Check content, build reproducibility, links, metadata, accessibility, asset weight, dependency risk, security headers, caching, compression, robots and sitemap behavior, Cloudflare configuration, rollback, and live performance. Findings are classified as fixed now, launch decision, or post-launch improvement.

Decisions

Approved

Keep all cited sources, simplify their statuses, remove homepage status copy, collapse glossary aliases beneath canonical rows, remove personal-name references outside the footer, and leave the DNS launch switch untouched.

Open questions

None. Any destructive, billing-related, or public-launch action pauses for approval; the default is to leave it unchanged and report it.
